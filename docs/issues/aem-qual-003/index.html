AEM-QUAL-003 SlingSchedulerUsage

Sling whiteboard scheduler used instead of Sling Scheduled Jobs (AMSCORE-554).

WARNING · 20 min fix · Security hotspot · Quality and Cloud Manager parity

Sling whiteboard scheduler used instead of Sling Scheduled Jobs (AMSCORE-554).

Why it matters

AMSCORE-554 flags the Sling whiteboard scheduler. AEM as a Cloud Service expects Sling Scheduled Jobs, which are cluster-aware: a job runs once across the publish tier instead of once per instance, and it survives a restart.

How to fix it

Implement a JobConsumer for the topic and schedule the run through the Sling Job API instead of Scheduler.addJob.

java · before
scheduler.add(new ImportJob(), options);
java · after
@Component(service = JobConsumer.class, immediate = true,
           property = JobConsumer.PROPERTY_TOPICS + "=acme/import")
public class ImportJobConsumer implements JobConsumer {

    @Override
    public JobResult process(Job job) {
        return JobResult.OK;
    }
}
