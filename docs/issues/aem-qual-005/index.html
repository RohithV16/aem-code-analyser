AEM-QUAL-005 AdministrativeAccessUsage

Deprecated administrative login or resource resolver API used; rejected on AEM as a Cloud Service.

ERROR · 25 min fix · Vulnerability · Quality and Cloud Manager parity

Deprecated administrative login or resource resolver API used; rejected on AEM as a Cloud Service.

Why it matters

Administrative logins and loginAdministrative bypass every permission check and are rejected by AEM as a Cloud Service. They also hide the real ACLs a feature needs.

How to fix it

Create a dedicated service user with a ServiceUserMapper mapping and request a service resource resolver for that subservice, then grant the service user exactly the permissions the feature needs.

java · before
ResourceResolver resolver = resolverFactory.getAdministrativeResourceResolver(null);
java · after
Map<String, Object> authInfo =
        Collections.singletonMap(ResourceResolverFactory.SUBSERVICE, "search");
try (ResourceResolver resolver =
             resolverFactory.getServiceResourceResolver(authInfo)) {
    // runs as the mapped service user, with its own ACLs
}
