AEM-PERF-002 UnclosedJcrSession

JCR Session obtained via repository login or adaptation is not logged out or closed.

ERROR · 30 min fix · Bug · Performance

JCR Session obtained via repository login or adaptation is not logged out or closed.

Why it matters

A JCR Session opened through repository.login() or adapted from a resolver must be logged out. An open session pins the observation queue and any pending changes, and on AEM as a Cloud Service leaked sessions show up as repository connection pressure.

How to fix it

Close the session in a finally block, or avoid the session entirely: the resource resolver API covers almost every read and write a component needs.

java · before
Session session = resolver.adaptTo(Session.class);
Node node = session.getNode(path);
java · after
try (ResourceResolver resolver = resolverFactory.getServiceResourceResolver(authInfo)) {
    Resource resource = resolver.getResource(path);
    if (resource != null) {
        ValueMap properties = resource.adaptTo(ValueMap.class);
    }
}
