AEM-PERF-001 UnclosedResourceResolver

ResourceResolver obtained via factory is not closed in try-with-resources or finally.

ERROR · 30 min fix · Bug · Performance

ResourceResolver obtained via factory is not closed in try-with-resources or finally.

Why it matters

A resolver obtained from the factory and never closed keeps its JCR session and its caches alive for the life of the JVM. AEM as a Cloud Service logs leaked resolvers and eventually refuses new ones, so the instance degrades instead of failing fast.

How to fix it

Always obtain the resolver in a try-with-resources block, or close it in a finally block, and never hand it to another thread.

java · before
ResourceResolver resolver = resolverFactory.getServiceResourceResolver(authInfo);
Resource resource = resolver.getResource(path);
return resource.adaptTo(ValueMap.class);
java · after
try (ResourceResolver resolver = resolverFactory.getServiceResourceResolver(authInfo)) {
    Resource resource = resolver.getResource(path);
    return resource == null ? Map.of() : resource.adaptTo(ValueMap.class);
}
