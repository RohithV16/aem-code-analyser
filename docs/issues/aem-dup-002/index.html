AEM-DUP-002 DuplicateOsgiConfiguration

Conflicting or duplicate OSGi configuration targeting the same PID in the same runmode context.

WARNING · 15 min fix · Code smell · Duplication

Conflicting or duplicate OSGi configuration targeting the same PID in the same runmode context.

Why it matters

Two files configuring the same PID in the same runmode context are both installed and the winner depends on install order. Values then differ between a fresh install and an incremental one — the classic "works on my instance" configuration bug.

How to fix it

Keep exactly one file per PID and runmode context and merge the properties into it. Split by runmode (config, config.author, config.publish) when the values genuinely differ.

text · before
ui.config/.../config/com.acme.SearchService.cfg.json         (limit = 100)
ui.config/.../config/com.acme.core.SearchService.cfg.json    (limit = 250)
text · after
ui.config/.../config/com.acme.core.services.SearchService.cfg.json   (limit = 250)
