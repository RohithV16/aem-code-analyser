AEM-CLOUD-009 UnreachableDeployableModule

A reactor module ships content or a bundle the all container never installs, or a bundle is embedded outside /install.

WARNING · 20 min fix · Bug · AEM as a Cloud Service

A reactor module ships content or a bundle the all container never installs, or a bundle is embedded outside /install.

Why it matters

AEM as a Cloud Service deploys one package per application: the container module (usually all) embeds and installs every other package, and must carry no content of its own. A module added to the reactor but never to <embeddeds> still builds and still passes the pipeline - the deployment simply does not contain it, and an author discovers the missing dialog weeks later. A bundle embedded outside an .../install path is worse: it travels inside the container and is never installed or started, so every component it declares stays absent with no error.

How to fix it

Add the module to the container's <embeddeds> under an install path, follow structure packages through <repositoryStructurePackages>, and move any content out of the container. Remove modules from the reactor when they are no longer deployed.

xml · before
<!-- all/pom.xml -->
<embeddeds>
    <embedded>
        <groupId>com.acme</groupId>
        <artifactId>acme.ui.content2</artifactId>
        <type>zip</type>
        <target>/apps/acme-packages/content/install</target>
    </embedded>
    <embedded>
        <groupId>com.acme</groupId>
        <artifactId>acme.core</artifactId>
        <target>/apps/acme-packages/application</target> <!-- no /install -->
    </embedded>
</embeddeds>
xml · after
<!-- all/pom.xml -->
<embeddeds>
    <embedded>
        <groupId>com.acme</groupId>
        <artifactId>acme.ui.content2</artifactId>
        <type>zip</type>
        <target>/apps/acme-packages/content/install</target>
    </embedded>
    <embedded>
        <groupId>com.acme</groupId>
        <artifactId>acme.core</artifactId>
        <target>/apps/acme-packages/application/install</target>
    </embedded>
</embeddeds>
