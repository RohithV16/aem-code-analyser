AEM-CLOUD-002 DeprecatedJspUsage

Legacy JSP file found in repository; AEMaaCS requires HTL.

WARNING · 30 min fix · Code smell · AEM as a Cloud Service

Legacy JSP file found in repository; AEMaaCS requires HTL.

Why it matters

AEM as a Cloud Service has no JSP support: a .jsp file is simply not rendered, so the page that uses it breaks after migration. JSPs also bypass HTL's contextual escaping.

How to fix it

Rewrite the JSP as an HTL template with a Sling Model for the logic, then delete the JSP and any Classic UI client libraries it depended on.

text · before
ui.apps/src/main/content/jcr_root/apps/acme/components/hero/hero.jsp
html · after
ui.apps/src/main/content/jcr_root/apps/acme/components/hero/hero.html

<div class="hero" data-sly-use.model="com.acme.core.models.HeroModel">
  <h2>${model.title}</h2>
</div>
