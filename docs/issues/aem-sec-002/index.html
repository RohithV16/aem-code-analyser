AEM-SEC-002 OpenRedirectOrSsrf

User-controlled input flows into a redirect or outbound HTTP request.

WARNING · 25 min fix · Code smell · Security

User-controlled input flows into a redirect or outbound HTTP request.

Why it matters

A request parameter that reaches sendRedirect or an outbound HTTP call lets an attacker choose the destination: an open redirect for phishing, or server-side request forgery against internal services (CWE-601).

How to fix it

Validate the destination against an allowlist of hosts or a fixed set of relative paths before redirecting, and never build an outbound URL from unvalidated input.

java · before
String target = request.getParameter("next");
response.sendRedirect(target);
java · after
String target = request.getParameter("next");
if (target != null && target.startsWith("/content/") && !target.startsWith("//")) {
    response.sendRedirect(response.encodeRedirectURL(target));
} else {
    response.sendRedirect("/content/acme/en.html");
}
