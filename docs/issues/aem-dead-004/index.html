AEM-DEAD-004 BrokenHtlReference

HTL template references non-existent Java class or Sling Model.

ERROR · 15 min fix · Bug · Dead code

HTL template references non-existent Java class or Sling Model.

Why it matters

An HTL expression that names a class which does not exist fails at render time, not at build time, so the page breaks in the author or publish instance rather than in CI. It is usually a package move or a rename that missed the template.

How to fix it

Point data-sly-use at the current fully qualified class name, and confirm the class lives in a bundle the template's package can see.

html · before
<sly data-sly-use.model="com.acme.core.models.OldHeroModel"/>
html · after
<sly data-sly-use.model="com.acme.core.models.HeroModel"/>
