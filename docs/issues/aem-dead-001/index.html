AEM-DEAD-001 OrphanedOsgiConfiguration

Orphaned OSGi Configuration without matching component or platform PID.

ERROR · 15 min fix · Bug · Dead code

Orphaned OSGi Configuration without matching component or platform PID.

Why it matters

A configuration file whose PID matches no component, no @ObjectClassDefinition and no platform factory PID never takes effect. At best it is dead weight in the content package; at worst it is a typo that silently stops the configuration you meant to ship, and the service starts with framework defaults on AEM as a Cloud Service.

How to fix it

Either delete the file or rename it so its PID is the component's fully qualified class name (or a factory PID the component declares). Verify with the Configuration console that the service now reads your properties.

text · before
ui.config/.../config/com.acme.OldSearchService.cfg.json
# class was renamed to SearchService; nothing reads this PID
text · after
ui.config/.../config/com.acme.core.services.SearchService.cfg.json
