AEM-QUAL-007 UnregistrableSlingModel

Sling Model injects a request-only type or @RequestAttribute without declaring a request adaptable.

WARNING · 25 min fix · Bug · Quality and Cloud Manager parity

Sling Model injects a request-only type or @RequestAttribute without declaring a request adaptable.

Why it matters

Sling Models resolves an injection against the adaptable, not against the request the adaptable came from. A model declared adaptables = Resource.class therefore cannot inject a request, a response or a @RequestAttribute: the class compiles, the bundle activates and the model registers, then request.adaptTo(Model.class) throws a ModelException (required injection) or silently renders null fields (optional injection).

How to fix it

If the model needs request state, declare SlingHttpServletRequest among its adaptables (usually alongside Resource.class). If it only needs resource data, inject that data from the resource with @ValueMapValue or @ChildResource instead of reaching for the request.

java · before
@Model(adaptables = Resource.class)
public class HeroModel {
    @Inject
    private SlingHttpServletRequest request;
}
java · after
@Model(adaptables = {Resource.class, SlingHttpServletRequest.class})
public class HeroModel {
    @Inject
    private SlingHttpServletRequest request;
}
