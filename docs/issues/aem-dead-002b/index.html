AEM-DEAD-002B UnconsumedOcdProperty

OCD Attribute method is never consumed by designating Java component.

WARNING · 10 min fix · Code smell · Dead code

OCD Attribute method is never consumed by designating Java component.

Why it matters

An OCD attribute that no code reads is a setting users can change with no effect. It usually survives a refactor that removed the code path but not the interface method.

How to fix it

Inject the configuration and read the attribute, or delete it from the @ObjectClassDefinition so the configuration console stops offering a dead switch.

java · before
@ObjectClassDefinition(name = "Search Service")
public @interface Config {

    // nothing in the bundle calls this
    int legacyTimeoutSeconds() default 30;
}
java · after
@Activate
void activate(Config config) {
    this.timeout = Duration.ofSeconds(config.timeoutSeconds());
}
