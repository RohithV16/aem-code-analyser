AEM-DEAD-002A GhostConfigurationProperty

Configuration property does not exist in target @ObjectClassDefinition.

WARNING · 10 min fix · Code smell · Dead code

Configuration property does not exist in target @ObjectClassDefinition.

Why it matters

A property that the component's @ObjectClassDefinition does not declare is dropped during binding. The configuration looks correct in the repository, so the symptom is an unexplained default value at runtime rather than a validation error.

How to fix it

Remove the property, correct its spelling, or add an @AttributeDefinition that declares it. Configuration and OCD must describe the same set of properties.

json · before
{
  "serachPath": "/content/dam"
}
json · after
{
  "searchPath": "/content/dam"
}
