AEM-CLOUD-004 DeprecatedAemApiUsage

Java source imports or uses an API deprecated in AEM as a Cloud Service (AMSCORE-553).

WARNING · 20 min fix · Code smell · AEM as a Cloud Service

Java source imports or uses an API deprecated in AEM as a Cloud Service (AMSCORE-553).

Why it matters

An API deprecated for AEM as a Cloud Service is removed or unmaintained in the product version the environment runs. The code compiles today and fails on the next upgrade.

How to fix it

Replace the call with its supported equivalent (for example the Sling ResourceResolverFactory instead of the deprecated CQ resolver helpers, and com.adobe.granite APIs instead of Classic UI ones). Check the AEM as a Cloud Service API reference for the replacement.
