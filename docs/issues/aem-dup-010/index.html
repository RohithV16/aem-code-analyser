AEM-DUP-010 DuplicateCodeBlock

Duplicate Java code block or method clone detected across repository classes.

WARNING · 30 min fix · Code smell · Duplication

Duplicate Java code block or method clone detected across repository classes.

Why it matters

Cloned code drifts: a fix applied to one copy silently misses the others, and every copy has to be re-tested. Duplication across bundles is usually a missing shared module.

How to fix it

Extract the duplicated block into a helper or an interface in the bundle that already owns the concept, and have both call sites use it.
