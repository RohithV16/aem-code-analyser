AEM-DEAD-005 OrphanedClientlibCategory

A client library category is never referenced by an HTL/JSP template or another client library.

INFO · 10 min fix · Code smell · Dead code

A client library category is never referenced by an HTL/JSP template or another client library.

Why it matters

A client library no page, component or other clientlib includes is still built and deployed. Dead clientlibs usually carry JS and CSS that also hide unused configuration and third-party dependencies.

How to fix it

Reference the category from an HTL template (data-sly-call with categories) or from another clientlib's categories dependency, or delete the clientlib folder.

xml · before
<jcr:root ... categories="[acme.legacy.grid]"/>
html · after
<sly data-sly-call="${clientlib.css @ categories='acme.legacy.grid'}"/>
