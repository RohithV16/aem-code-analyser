AEM-A11Y-002 LinkWithoutAccessibleName

HTL anchor has no href/data-sly-attribute.href, or no accessible name for icon-only content (WCAG 2.4.4).

WARNING · 10 min fix · Bug · Accessibility

HTL anchor has no href/data-sly-attribute.href, or no accessible name for icon-only content (WCAG 2.4.4).

Why it matters

An <a> without href is not focusable, so keyboard users cannot reach it even though pointer users can click the styled element. An icon-only link is the mirror defect: it has no text for a screen reader to announce, so the link reads as an empty control. Both are WCAG 2.4.4 failures that a rendered-DOM audit finds only after deploy, while the template edit is cheap.

How to fix it

Keep href on every element styled as a link (bind it with data-sly-attribute.href when it is dynamic), and give an icon-only link an aria-label or visually hidden text that names its destination.

html · before
<!-- components/icon-link/icon-link.html -->
<a class="icon-link"><img src="${model.icon}" alt=""></a>
html · after
<!-- components/icon-link/icon-link.html -->
<a class="icon-link" href="${model.url}" aria-label="${model.label}">
    <img src="${model.icon}" alt="">
</a>
