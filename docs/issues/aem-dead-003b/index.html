AEM-DEAD-003B UnusedSlingModel

Sling Model has zero Java adaptations and no resourceType binding.

INFO · 5 min fix · Code smell · Dead code

Sling Model has zero Java adaptations and no resourceType binding.

Why it matters

A Sling Model that no template adapts from and that no resourceType binds is never instantiated. It is often a model that survived the deletion of its component.

How to fix it

Bind it with @Model(resourceType = ...) so the component uses it, adapt it explicitly from HTL with data-sly-use, or delete it.

java · before
@Model(adaptables = Resource.class)
public class TeaserModel { }
java · after
@Model(adaptables = Resource.class,
       resourceType = "acme/components/teaser")
public class TeaserModel { }
