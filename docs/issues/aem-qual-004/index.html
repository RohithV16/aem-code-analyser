AEM-QUAL-004 UnsafeComponentState

Non-thread-safe or session-bound object stored in OSGi component field (AEM-3).

ERROR · 20 min fix · Bug · Quality and Cloud Manager parity

Non-thread-safe or session-bound object stored in OSGi component field (AEM-3).

Why it matters

SlingHttpServletRequest, ResourceResolver and JCR Session are bound to one thread and one request. Stored in a component field, they leak across requests: closed resolvers are reused, sessions go stale after a restart, and the component is no longer thread-safe (Cloud Manager check AEM-3).

How to fix it

Keep only immutable, thread-safe collaborators in fields. Obtain request-scoped objects as parameters or from the request, and close them where they were created.

java · before
@Component(service = NavigationService.class)
public class NavigationService {

    private ResourceResolver resolver;   // one request's resolver, shared by all

    @Activate
    void activate(ResourceResolverFactory factory) { }
}
java · after
@Component(service = NavigationService.class)
public class NavigationService {

    @Reference
    private ResourceResolverFactory resolverFactory;

    public List<String> paths(Resource resource) {
        // the caller owns the request-scoped resolver
        return collect(resource);
    }
}
