AEM-QUAL-006 ResolverStoredInComponentField

OSGi component stores a request-scoped ResourceResolver or JCR Session in an instance field.

WARNING · 15 min fix · Code smell · Quality and Cloud Manager parity

OSGi component stores a request-scoped ResourceResolver or JCR Session in an instance field.

Why it matters

Storing a request-scoped resolver or session in an OSGi component field keeps one request's state alive for every later request, which leaks resolvers and can serve stale content.

How to fix it

Obtain the resolver or session per request and close it in the same scope. The thread-safety owner for this check is AEM-QUAL-004 (ERROR); this id is retained so existing baselines and SARIF consumers keep working.
