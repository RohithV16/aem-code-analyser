AEM-DEAD-003C InactiveDelayedComponent

Component provides no service interfaces and immediate = false.

WARNING · 10 min fix · Code smell · Dead code

Component provides no service interfaces and immediate = false.

Why it matters

With immediate = false and no service interface, an OSGi component is delayed and nothing can ever obtain it, so its @Activate never runs. Any startup work it performs — schedulers, caches, listeners — silently does not happen.

How to fix it

Set immediate = true for components that must start with the bundle, or register a service interface so the component is created on first injection. Delete it if neither is intended.

java · before
@Component(immediate = false)
public class CacheWarmer {
    @Activate
    void activate() { /* never called */ }
}
java · after
@Component(immediate = true)
public class CacheWarmer {
    @Activate
    void activate() { warm(); }
}
