AEM-QUAL-008 UnprovidedMandatoryReference

Mandatory @Reference target is declared by project sources but registered by no component.

ERROR · 20 min fix · Bug · Quality and Cloud Manager parity

Mandatory @Reference target is declared by project sources but registered by no component.

Why it matters

A Declarative Services component with an unsatisfied mandatory reference never activates. The bundle stays Active and the code compiles because the target type is on the classpath, so the failure is invisible until the servlet 404s or the scheduled job never fires.

How to fix it

Register an implementation with @Component(service = Target.class), or declare the reference cardinality = ReferenceCardinality.OPTIONAL when activation must not depend on it. Confirm in the Felix console that the component is satisfied.

java · before
@Component(immediate = true, service = ElasticIndexOrchestrator.class)
public class ElasticIndexOrchestrator {
    // ResourceResolverProvider is declared in this project...
    @Reference private ResourceResolverProvider resolverProvider;
}
// ...but no @Component implements or registers it
java · after
@Component(service = ResourceResolverProvider.class)
public class ResourceResolverProviderImpl implements ResourceResolverProvider {
    public ResourceResolver obtainResourceResolver() { ... }
}
