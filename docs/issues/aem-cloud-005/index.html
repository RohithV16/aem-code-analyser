AEM-CLOUD-005 InvalidRunmodeFolder

OSGi configuration lives in a runmode folder that is not a recognised AEM runmode.

WARNING · 5 min fix · Code smell · AEM as a Cloud Service

OSGi configuration lives in a runmode folder that is not a recognised AEM runmode.

Why it matters

Only the documented runmodes are applied by AEM as a Cloud Service. A configuration in an unrecognised folder is never activated, so the setting silently does not apply.

How to fix it

Move the file to a recognised folder — config, config.author, config.publish, config.dev, config.stage, config.prod — or delete it when the runmode no longer exists.

ui.config/.../config.author.dev.local/com.acme.SearchService.cfg.json
