AEM-CLOUD-001 HardcodedCloudSecret

Plaintext secret or password found in OSGi configuration file.

ERROR · 15 min fix · Vulnerability · AEM as a Cloud Service

Plaintext secret or password found in OSGi configuration file.

Why it matters

A plaintext secret in a content package is readable by anyone with repository access, ends up in every environment's backup, and cannot be rotated without a code change. AEM as a Cloud Service refuses to start a service with a secret that was not supplied through a secret variable.

How to fix it

Replace the value with a secret placeholder and define the variable in Cloud Manager (or in the local .env for the SDK). Never commit the real value.

json · before
{
  "apiKey": "sk_live_9f3ac1e8b0"
}
json · after
{
  "apiKey": "$[secret:acme.apiKey]"
}
