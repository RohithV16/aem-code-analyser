AEM-DEAD-007 BrokenHtlInclude

HTL data-sly-include target is missing or forms an include cycle.

WARNING · 15 min fix · Bug · Dead code

HTL data-sly-include target is missing or forms an include cycle.

Why it matters

Sightly resolves data-sly-include while rendering, so a renamed or mis-pathed include is invisible to the build. It surfaces only as an empty region on one page, long after the template was moved. An include cycle is worse: rendering recurses until the request is aborted.

How to fix it

Correct the include path to an existing template relative to the including file, or break the cycle by factoring the shared markup into a leaf template that both sides include.

html · before
<!-- components/card/card.html -->
<sly data-sly-include="card-details.html"/>

<!-- components/card/details.html (renamed to card-details.html) -->
html · after
<sly data-sly-include="card-details.html"/>
